Documentation Tab

The Documentation tab holds full documentation, written in AsciiDoc, for the element selected in the Outline view. The AsciiDoctor builders include it in the documentation they generate from the profile, so this is where you write the explanations, examples and notes that a reader of the published profile needs.

[Screenshot: the Documentation tab with a class selected, showing the heading and AsciiDoc text.]

Writing Documentation

Select an element in the Outline and type in the text area. The heading above the text area tells you what kind of element you are documenting:

HeadingSelected element
Profile Level DocumentationThe profile itself
Class DocumentationA concrete class
Abstract Class DocumentationA class that is not concrete
Enumeration DocumentationAn enumeration
Compound DocumentationA compound
Attribute DocumentationAn attribute
Association DocumentationAn association
Enum Literal DocumentationA value of an enumeration

The text is stored in the profile when you leave the text area, and saved to disk when you save the profile (Ctrl+S). Use ordinary AsciiDoc markup: paragraphs, lists, tables, source blocks and links.

Documentation and Description

The Documentation tab and the Description tab hold different text. The Profile Description on the Description tab is a short plain-text description that most builders carry into the schemas they generate. The Documentation tab holds longer AsciiDoc text for the generated documentation. Use the description for what a schema reader needs, and the documentation for everything a reader of the published profile needs.
