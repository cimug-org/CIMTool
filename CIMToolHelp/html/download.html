CIMTool Help

Download

New releases of CIMTool are published on the CIMTool website. To download a release, open one of these pages:

  • Download the latest CIMTool release (cimtool.ucaiug.io)
  • All CIMTool releases (GitHub), for earlier releases and their release notes

Both links open in your web browser and need internet access. On a computer without internet access, download the release on a connected computer and copy it across.

Windows Firewall Prompt on First Start

The first time a new installation of CIMTool starts, Windows may ask whether to allow CIMTool.exe to access public and private networks. CIMTool does not need to accept connections from other computers, so you can choose Cancel. Everything CIMTool does with the network, such as opening links in your web browser, still works.
