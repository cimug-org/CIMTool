CIMTool Help

CIMTool Topics

Help for CIMTool, the open-source tool for building CIM profiles and generating schemas, documentation and other artifacts from them. Topics are grouped by the kind of work they cover. Press F1 in any CIMTool view or Profile Editor tab to open the help for that part directly, or use the CIMTool Context Help panel, which follows the part you are working in.
