Documentation View

The Documentation view shows the schema's description of whatever you select in the CIM: a class, attribute, association, enumeration or package. It saves you opening the Profile Editor's Description tab just to read what the CIM says about an element.

[Screenshot: the Documentation view, in the CIMTool perspective's bottom view stack, showing the description of a class selected in the Project Model.]

What the View Shows

The view shows two things, one after the other:

  1. The name of the selected element.
  2. Its description from the schema: the documentation written for it in the UML model (for example in Enterprise Architect) and carried into the project's schema on import. If the schema has no description for the element, only the name is shown.

The description always comes from the schema, even when you select an element of a profile. It is the same text as the read-only Schema Description on the Profile Editor's Description tab. The view never shows a profile's own text: the Profile Description and the Documentation tab's AsciiDoc are only on those tabs. See Project and Profile Documentation for where each kind of text is used.

The view is read-only, with a pale yellow background. You can select its text and copy it with Ctrl+C.

How It Follows Your Selection

The view follows the selection anywhere in the workbench that shows schema or profile elements, including:

  • the Project Model view;
  • the Outline view of the Profile Editor;
  • the profile pane and schema pane of the Profile Editor's Add/Remove tab;
  • the Model Browser, which opens a schema file.

Selecting a file or folder in the Project Explorer does not change the text, but it does switch the view to that file's project, so that the next element you select is looked up in the right schema. The view reads the project's merged schema: every schema file in the project's Schema folder combined, so an element from an extension schema is found as well as one from the base CIM.

Opening the View

In the CIMTool perspective the Documentation view is a tab in the stack below the editor, next to the Profile Real-Time Preview, PlantUML Svg and Properties views. If it has been closed, choose Window > Show View > Documentation, or Window > Show View > Other... and then CIMTool > Documentation. The Browsing perspective also shows it, on the right.
